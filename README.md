# 📊 Automated Data Cleaning & Visualization Tool

## 📌 Overview

An automated Python tool that cleans raw data from Excel, CSV, or SQL sources, handles missing values and duplicates, exports the cleaned dataset, and automatically generates 4-5 insightful visualizations.

## 🎯 Objective

The main objective of this project is to simplify the data preparation and visualization process by automating common data-cleaning tasks and generating charts from the cleaned dataset.

## 🔄 Workflow

1. 📥 Import raw data from Excel, CSV, or SQL.
2. 🧹 Clean and preprocess the data.
3. 🚫 Handle missing and null values.
4. ♻️ Remove duplicate records.
5. 🔍 Validate and transform data types.
6. 💾 Save the cleaned dataset.
7. 📤 Export the cleaned data as Excel, CSV, or SQL.
8. 📈 Automatically generate 6–8 visualizations.

## 📈 Visualizations

The project automatically generates 6–8 charts based on the available data, including:

- 📊 Bar charts
- 📈 Line charts
- 🥧 Pie charts
- 📉 Distribution charts
- 🔗 Correlation visualizations
